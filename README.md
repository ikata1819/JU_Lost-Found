# JU Lost & Found

**JU Lost & Found** is a web application designed to help students of Jahangirnagar University report, track, and find lost and found items on campus.

## Features
- **Report Lost Items:** Submit details of lost items.
- **Report Found Items:** Notify about found items to help owners retrieve them.
- **Search & Filter:** Easily search for items by type, location, or date.
- **User-Friendly Interface:** Clean and responsive design for mobile and desktop.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/ju-lost-found.git

2. Import the database `ju_lost_fpund.sql` to your MySQL server.
3. Update the database connection in `db-config.php`.
4. Run the application on a local server (e.g., XAMPP, WAMP).
